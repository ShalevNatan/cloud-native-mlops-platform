# Architecture

## Status

Architecture design in progress.

## High-Level Direction

The platform will run a machine learning workload on Amazon EKS.

AWS infrastructure will be provisioned using Terraform.

Application delivery will use CI/CD and GitOps.

The platform will include observability and an MLOps lifecycle.

## Initial Components

- AWS
- Amazon EKS
- Terraform
- Docker
- Amazon ECR
- GitHub Actions
- ArgoCD
- MLflow
- Prometheus
- Grafana
