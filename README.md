# Cloud-Native MLOps Platform

A production-oriented cloud-native platform for deploying and operating
machine learning workloads on AWS Kubernetes infrastructure.

## Status

🚧 Project initialization

## Goals

Build a reproducible AWS-based Kubernetes platform for ML workloads.
Allow ML engineers to build, run, track, and deploy ML workloads without manually managing underlying infrastructure.
Provide reproducible training environments using containers and Kubernetes.
Provide persistent storage and artifact management for datasets, models, and experiment outputs.
Automate application and ML workload delivery through CI/CD and GitOps.
Provide experiment tracking and model lifecycle management.
Provide observability for both infrastructure and ML workloads.
