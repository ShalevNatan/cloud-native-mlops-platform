# Cloud-Native MLOps Platform

A production-oriented cloud-native platform for deploying and operating
machine learning workloads on AWS Kubernetes infrastructure.

## Status

🚧 Project initialization

## Goals

- AWS infrastructure provisioned with Terraform
- Kubernetes workloads running on Amazon EKS
- CI/CD with GitHub Actions
- GitOps deployment with ArgoCD
- ML lifecycle management with MLflow
- Observability with Prometheus and Grafana
- ML-powered workload prediction and scaling
